# Use Bun throughout the toolchain

The site will use Bun 1.3.14 for dependency installation, lockfile management, script execution, local development, validation, and its Cloudflare Pages build environment. This deliberately replaces npm end-to-end so contributors and deployment use one toolchain rather than mixing Bun locally with npm in production; the exact version makes local and deployed builds reproducible. Local project commands will fail unless they run on the pinned Bun version. Dependencies will use Bun's hoisted linker for npm-compatible resolution, retain normal caret ranges in `package.json`, and be refreshed to their newest releases, including majors. Any resulting incompatibilities will be resolved as part of the migration; the resulting compatible set will be recorded in `bun.lock`. Cloudflare Pages preview and production builds will set `BUN_VERSION=1.3.14` and `SKIP_DEPENDENCY_INSTALL=true`, use `bun ci && bun run build`, and publish `dist`.
