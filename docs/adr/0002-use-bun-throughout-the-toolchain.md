# Use Bun throughout the toolchain

The site will use Bun for dependency installation, lockfile management, script execution, local development, validation, and its Cloudflare Pages build environment. This deliberately replaces npm end-to-end so contributors and deployment use one toolchain rather than mixing Bun locally with npm in production. Dependencies use Bun's hoisted linker for npm-compatible resolution, retain normal caret ranges in `package.json`, and are recorded in `bun.lock`. Cloudflare Pages preview and production builds use `bun install --frozen-lockfile && bun run build` and publish `dist`.
